# Wanxiang Jingting · Signed Updates

Public, signed update channel for independent clones of 万象镜厅 / 萬象鏡廳 / Hall of Myriad Mirrors / 万象鏡庁 / Salón de los Mil Espejos / 만상경청.

This repository contains only version feeds and signed update packages. It does not contain signing private keys, Agent identities, owner profiles, authentication, friends, conversations, memories, test results, runtime databases, SSH information, or private configuration.

Clones verify the publisher signature, package checksum, and every file checksum before installation. They back up the previous version, update only allowlisted public components, validate the installation, and roll back on failure. The updater runs locally without calling a model.

Source development remains in a separate private repository.
